# TUWA SDK: Next.js and Solana

[![License: MIT-0](https://img.shields.io/badge/license-MIT--0-blue.svg)](./LICENSE)

A Next.js app for Solana with Wallet Standard wallets and tracked program calls, built on the TUWA SDK (`@tuwaio/sdk` with `@tuwaio/solana-sdk`). The build contains no EVM code of TUWA. It is a template of [Cosmos Playground](https://github.com/TuwaIO/cosmos-playground); the [React transaction tracking guide](https://docs.tuwa.io/guides/react-transaction-tracking) explains the same code step by step (Solana tab).

---

## 🚀 Quick Start

```bash
npx @tuwaio/create-cosmos-playground   # choose nextjs-solana
cd my-app
cp .env.example .env
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with a Solana wallet extension (for example Phantom or Solflare) set to devnet. Node.js 20.9 or newer is required; the only variable in `.env` is optional.

---

## 🎯 What It Shows

- **Wallet connection** with the Nova Connect modals on Satellite Connect, for every wallet that supports Wallet Standard. Satellite Connect reconnects the last wallet after a page reload.
- **Tracked transactions** with Pulsar and the Nova Transactions modals and toasts: a counter program on devnet, with the client generated by Codama from the Anchor IDL. Create a counter account, increment, decrement or close it.
- **Transaction history** saved to `localStorage`, with tracking that resumes after a reload.

## 📦 TUWA Packages

| Import                                                                            | Used for                                                              |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| `@tuwaio/sdk/nova-connect`, `/nova-connect/components`, `/nova-connect/satellite` | `NovaConnectProvider`, `ConnectButton`, the Satellite Connect store   |
| `@tuwaio/sdk/nova-transactions`, `/nova-transactions/providers`                   | `NovaTransactionsProvider`, `TxActionButton`, `HashLink`              |
| `@tuwaio/sdk/pulsar`, `@tuwaio/sdk/orbit`                                         | The Pulsar store and the network helpers                              |
| `@tuwaio/solana-sdk/*`                                                            | The Solana adapters, `SolanaConnectorsWatcher`, `signAndSendSolanaTx` |

The transaction signer comes from `@solana/react` (`useWalletAccountTransactionSendingSigner`).

## 🔧 Environment Variables

| Variable                  | Description                                                                                               |
| ------------------------- | --------------------------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_ALCHEMY_KEY` | Alchemy key for the Solana Mainnet RPC URL. Default: `https://api.mainnet-beta.solana.com` (rate-limited) |

The devnet program uses the public `https://api.devnet.solana.com`.

## 📁 Project Structure

```
src/
├── app/           # Next.js App Router: layout and page
├── components/    # Header, home page, the transaction block and its buttons
├── configs/       # Solana RPC URLs
├── constants.ts   # Address of the counter program
├── hooks/         # Pulsar store, store of the counter accounts
├── programs/      # Codama client of the program (generated/ is rebuilt by `pnpm generate:solana`)
├── providers/     # Satellite Connect, Nova Connect and Nova Transactions providers
├── styles/        # Tailwind CSS v4 and the Nova stylesheets
├── targets/       # Anchor IDL of the program
└── transactions/  # The transaction actions and their types
```
