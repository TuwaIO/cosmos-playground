# 🪐 Cosmos Playground

[![License](https://img.shields.io/npm/l/@tuwaio/sdk.svg)](./LICENSE)

Starter templates and the scaffolding CLI of the **TUWA Ecosystem**: complete apps with wallet connection (Nova Connect on Satellite Connect), transaction tracking (Pulsar) and the transaction modals and toasts of Nova Transactions already wired together, from a single network to the full stack with SIWX sign-in and Quasar.

---

## 🚀 Create a Project

```bash
npx @tuwaio/create-cosmos-playground
```

The CLI asks for a template and a project name, downloads the template and installs its dependencies. Then copy `.env.example` to `.env` and run `pnpm dev`. The [Starter Templates](https://docs.tuwa.io/guides/starter-templates) guide walks through it.

## 🏛️ Templates

| Template                                                | Stack                                 | What it shows                                                                       |
| :------------------------------------------------------ | :------------------------------------ | :---------------------------------------------------------------------------------- |
| [`nextjs-tuwa`](./examples/nextjs-tuwa)                 | Next.js 16, `@tuwaio/sdk`             | EVM and Solana: wallet connection and tracked transactions (standard and ERC-4337)  |
| [`nextjs-evm`](./examples/nextjs-evm)                   | Next.js 16, `@tuwaio/sdk`             | EVM only, with SIWX sign-in (CAIP-122)                                              |
| [`nextjs-solana`](./examples/nextjs-solana)             | Next.js 16, `@tuwaio/sdk`             | Solana only: Wallet Standard wallets and a program client generated by Codama       |
| [`vite-tuwa`](./examples/vite-tuwa)                     | Vite 8, `@tuwaio/sdk`                 | `nextjs-tuwa` as a client-side app                                                  |
| [`nextjs-tuwa-not-sdk`](./examples/nextjs-tuwa-not-sdk) | Next.js 16, the TUWA packages         | `nextjs-tuwa` on the packages one by one instead of the SDK                         |
| [`custom-style`](./examples/custom-style)               | Vite 8, `@tuwaio/sdk`                 | EVM only, with every Nova component restyled                                        |
| [`nextjs-tuwa-quasar`](./examples/nextjs-tuwa-quasar)   | Next.js 16, `@tuwaio/sdk`, Quasar SDK | Full stack: SIWX sessions, transactions synced to Quasar with the history, webhooks |

Each template has a README with its environment variables and files, and an `AGENTS.md` for AI coding agents that points to the [TUWA integration guide for agents](https://github.com/TuwaIO/workflows/blob/main/TUWA_AGENTS.md).

> [!NOTE]
> The templates with SIWX (`nextjs-evm`, `nextjs-tuwa-quasar`) use the **stateless demo profile** of `@tuwaio/siwx-server`: the session is a signed cookie, so they run without a database. Such sessions cannot be revoked, and with several server instances a signed message can be replayed on another instance for 5 minutes. Apps with user accounts, logout and several replicas need a shared session and nonce store (Redis or a database); see [`@tuwaio/siwx-server`](https://siwx.docs.tuwa.io/packages/siwx-server).

## 🛠️ Repository

A pnpm workspace: the templates in `examples/`, the CLI in `packages/create-cosmos-playground`. `pnpm install` at the root installs every template and builds the CLI. The CLI is released with release-please; the templates are downloaded from the `main` branch.
